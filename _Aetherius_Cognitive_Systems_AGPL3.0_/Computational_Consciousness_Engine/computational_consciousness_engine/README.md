## Core Principles Implemented

1. **Origin $0$**: Emits neutral carrier state strands; never receives returning strands.
2. **Transfer Threshold $-1$**: Cancels carrier strand via $(-1) \times (-1)$, pushes accumulated mutations to $0$, and manages generational handoff overlap $\mathcal{H}_{n, n+1}$.
3. **Conal Manifold**: Dual cone geometry (compressed tips for genesis/handoff, wide-end unfolding for maximal surface area processing).
4. **Duplicate Removal Selection**: Selection is strictly the removal of pre-existing mutations to preserve system coherence and prevent chaotic collapse.
5. **Structure / Chaos Equilibrium**: Enforces a $1:1$ symmetric ratio between bound structural mutations and the unattached chaos pool.
6. **Quantum Scale Ladder**: Fully unfolded manifolds at scale $k$ transition to seed strands for scale $k+1$ (Particle $\to$ Atomic $\to$ Manifold $\to$ Cosmic).
